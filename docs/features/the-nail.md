# The Nail — unfinished and disabled

[All features](README.md) · [Configuration](configuration.md)

**Status:** unsupported inactive code. **Default:** disabled in code, with no
registered configuration key or MCM menu entry. **Documentation target:**
Repentance+ v1.9.7.17 (owner executable 1.9.7.17.J460).

The helper appears intended to supplement The Nail's soul-heart output, but the
pack currently makes **no active Nail adjustment**. Its enabling flag is false,
the pre-use path is commented out, and the use path is gated by that false flag.
There is no supported new-run or Continue choice that activates it.

The helper contains a call to add one half-heart unit of soul health if invoked;
that is not a supported payout promise or evidence of a complete vanilla revert.
No active character/mode behavior or working target-build validation is claimed.
Leave this unfinished code out of the supported feature count.
